B. QUA WORDPRESS HTTP API
======================================================================
Kiem chung ban vá: dat 'httpversion' => '1.1' co du de cuu khong.
Can biet vi WordPress co the VAN tu gan 'Connection: close' — ma rieng
header do cung du gay loi 56 (xem muc A).

  wp_remote_get MAC DINH (httpversion 1.0)     LOI   http_request_failed
                                                     cURL error 56: OpenSSL SSL_read: error:0A000126:SSL routines::unexpected eof while reading, errno 0
  wp_remote_get + httpversion '1.1'            LOI   http_request_failed
                                                     cURL error 56: OpenSSL SSL_read: error:0A000126:SSL routines::unexpected eof while reading, errno 0
  wp_remote_get + 1.1 + Connection: keep-alive OK    HTTP 500  109 byte

  --- WordPress THUC SU gui di nhung dong nao (bien the httpversion 1.1) ---

    Connection: close

  => BAN VÁ CHUA DU. Dat httpversion 1.1 khong cuu duoc; xem cac dong
     '>' o tren de biet WordPress con gan them header gi.
